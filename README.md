- 🎵 點歌：右上角「點歌」或走到休息區左上角的 🎧 DJ 台，打歌名搜尋 YouTube（或直接貼連結）就能排進隊伍。全場一台點唱機，所有人同步聽同一首；點歌的人可以直接切歌，其他人超過一半同意也能切。左上角的黑膠唱盤可以調音量、靜音（手機如果沒聲音，按「點一下開始聽」）

技術：Phaser 3（前端 2D 遊戲引擎）+ Node.js + Express + Socket.IO（即時多人同步）。不需要資料庫，也不需要物理引擎。

朋友打開網址會先看到「颱風假開趴」報名頁：上傳大頭照、填暱稱、拿手歌、今晚要喝的酒，選一張 VIP 卡顏色，就會生成：

- 專屬的「防颱總部」VIP 通行證
- 9:16 會動的 IG 限時動態影片（mp4），手機可直接分享到 IG 或存到相簿
- 報名完才會出現「進入颱風天防衛總部」的入口，暱稱會自動帶進遊戲

報名時會一起建立帳號，邀請函和角色存在伺服器的 `data/accounts.json`（不用資料庫），下次登入就能拿回來。

## 架站與上版（給站長）

總部架在自己的電腦上（Windows 的 WSL 裡），用 Cloudflare 通道讓朋友連進來，不需要 public IP 或資料庫。買一個網域就有固定網址（第 6 步）；還沒買的話可以先用快速通道。

### 第一次架站

1. 在 WSL 裡裝好 [Node.js](https://nodejs.org/)（18 版以上）和 git。
2. 抓程式碼、裝套件：

   ```bash
   git clone https://github.com/dy850078/typhoon-defense-hq.git
   cd typhoon-defense-hq
   npm install
   ```

3. 建立設定檔：

   ```bash
   cp .env.example .env
   ```

   打開 `.env` 填上：`ADMIN_PASSWORD`（管理員密碼）、`JITSI_ROOM`（固定的視訊房間名稱，取個不好猜的）、小樹屋語音的 `CF_TURN_KEY_ID` / `CF_TURN_KEY_TOKEN`（見下面「小樹屋語音」）。`.env` 不會被推上 GitHub；指令上直接帶的變數優先於 `.env`。其他可以設的值見下面「設定」。

4. 安裝 cloudflared（WSL / Ubuntu 用 [官方說明](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 的 `.deb`；macOS：`brew install cloudflared`；Windows：`winget install --id Cloudflare.cloudflared`）。
5. 讓上版時能把版本標籤推上 GitHub（只要做一次）：

   ```bash
   gh auth login
   gh auth setup-git
   ```

   沒做也能上版，只是標籤會推不上去，終端機會提醒你之後手動 `git push origin <版本>`。

6. 設定固定網址（只要做一次）。先在 Cloudflare 後台的 Domain Registration 買一個網域（例如 `example.com`），再執行：

   ```bash
   npm run tunnel:setup -- hq.example.com
   ```

   網域可以用整個 `example.com`，也可以用子網域 `hq.example.com`。它會依序：檢查 cloudflared → 沒登入過就開瀏覽器登入 Cloudflare（選你的網域按 Authorize）→ 建立名叫 `hq` 的通道 → 把網域指到通道 → 寫通道設定檔 `~/.cloudflared/hq.yml` → 在 `.env` 記上 `TUNNEL=hq` 和 `PUBLIC_URL`。重跑也沒關係，做過的步驟會跳過；想換網域就帶新的網域再跑一次。

### 每次開站

```bash
npm run serve
```

伺服器和通道會一起開，看到 `🌐 通道已連上：https://hq.example.com` 就可以把網址傳給朋友。網址固定不變，伺服器關掉再開、電腦重開都一樣。自己測試直接開 <http://localhost:3000>。

`npm run serve` 會在 node 關掉後自動重開（意外當掉也會），上版時不用 Ctrl+C。如果 30 秒內連續當 3 次，它會停下來，先看上面的錯誤訊息。通道斷線也會自己重新連上。只想在本機試玩、不需要自動重開和通道的話，用 `npm start` 也可以。

> 電腦關機、睡眠或關掉終端機，大家就會斷線，開回來之後同一個網址就能繼續玩。

### 伺服器沒開時顯示休息頁（只要做一次）

沒開伺服器時，朋友點網址會看到 Cloudflare 的錯誤頁。在 Cloudflare 放一個小程式（Worker，免費）擋在網域前面，就會改成顯示「總部休息中」。這一頁開著就好，每 30 秒會檢查一次，總部一開門就自動帶大家進去。伺服器有開的時候，所有東西都原封不動轉給總部。

1. Cloudflare 後台 → **Workers & Pages** → **Create** → **Create Worker**，名稱取 `hq-offline`，按 **Deploy**。
2. 按 **Edit code**，把裡面的程式碼全部刪掉，貼上 [`cloudflare/offline-worker.js`](cloudflare/offline-worker.js) 的全部內容，按 **Deploy**。
3. 回到這個 Worker 的 **Settings** → **Domains & Routes** → **Add** → 選 **Route**（不要選 Custom domain，那個會蓋掉通道的設定）：Zone 選你的網域，Route 填 `你的網域.com/*`，按 **Add route**。
4. 關掉伺服器，打開網址看看，應該會看到休息頁。

免費方案每天可以處理 10 萬個請求，20 個人遠遠用不完；萬一超過，Cloudflare 會直接放行到總部，不會擋人。之後改了 `offline-worker.js`，重做第 2 步就好。

### 還沒買網域的話：快速通道

`.env` 沒有 `TUNNEL` 時，`npm run serve` 只開伺服器。另外開一個終端機：

```bash
cloudflared tunnel --url http://localhost:3000
```

會出現 `https://xxxx-xxxx.trycloudflare.com`，把這個網址傳給朋友。

> ⚠️ 快速通道的網址每次重開都會變，大家要重新拿網址、重新登入（角色存在帳號裡不會不見，但瀏覽器裡的小設定會重置）。這個終端機不要關，上版只重開 node，交給 `npm run deploy` 就好。

### 搬到固定網址

從快速通道換成固定網址那天：伺服器開著的話先用管理員介面的「預告更新」幫大家存檔，再照上面第 6 步設定、重開 `npm run serve`。公告新網址，請大家到新網址重新登入一次就好，角色、等級、裝備都存在 `data/accounts.json` 裡。忘記密碼的人到 `/admin.html` 幫他重設。

### 上版

PR 合併進 main 之後：

1. 打開管理員介面 `/admin.html`，在「預告更新」選 1／3／5 分鐘按「發布」，大家畫面上方會倒數；倒數完會先幫大家存好角色，管理員頁顯示「可以重啟了」。打王、遊戲室進行中時盡量避開（王的血量、分數會重置）。
2. 看到「可以重啟了」之後，**再開一個終端機**（開著 `npm run serve` 的那個不要動），在專案資料夾執行：

   ```bash
   npm run deploy
   ```

它會依序：確認這台電腦沒有改到一半的檔案、確認在 main 分支 → `git pull`（套件有變自動 `npm install`）→ 收集 `changes/` 裡還沒公告過的更新小紙條，寫進 `data/releases.json` → 打版本標籤 `vYYYY.MM.DD-N` 並推上 GitHub → 通知 `npm run serve` 存檔後用新版本重開。玩家畫面會跳「總部更新了」，重新整理後第一次進來會看到這次的更新內容。

每個 PR 的更新小紙條寫法見 [changes/README.md](changes/README.md)。

### 上版遇到狀況

| 畫面上看到 | 怎麼辦 |
| --- | --- |
| 「這些檔案在這台電腦上被改過」，列出 `package-lock.json` | 通常是 `npm install` 自己改的，丟掉就好：`git checkout package-lock.json`，再跑一次 `npm run deploy` |
| 「這些檔案在這台電腦上被改過」，列出其他檔案 | 先 `git diff` 看改了什麼，不要的話 `git checkout <檔名>` |
| 「現在在 xxx 分支」 | `git checkout main` 再跑一次 |
| 「已經是最新版了」 | 沒有新東西所以沒重開；真的要重開伺服器用 `npm run deploy -- --force` |
| 「標籤沒推上去」 | 上版已經成功。照上面「第一次架站」第 5 步做 `gh auth login` + `gh auth setup-git`，再手動 `git push origin <版本>` |
| 「找不到用 npm run serve 開的伺服器」 | 伺服器是用 `npm start` 開的，或已經關掉了。到開伺服器的終端機按 Ctrl+C，改用 `npm run serve` 開 |
| `git pull` 失敗（不能 fast-forward） | 這台電腦上有沒推上去的 commit，先看 `git log origin/main..` 再決定要不要留 |

### 不用 Cloudflare 的話：ngrok

1. 到 <https://ngrok.com/> 註冊並安裝，照網站指示設定 authtoken。
2. 執行 `ngrok http 3000`，把畫面上 `Forwarding` 那行的 https 網址傳給朋友。

免費版的網址一樣每次重開都會變，注意事項跟上面快速通道相同。

## 帳號和管理員介面

- 首頁是登入頁：已經有帳號的人輸入帳號密碼就能拿回邀請函；第一次來的人按「報名領邀請函」，報名時順便設定帳號密碼
- 以前沒有帳號時報名過的人，邀請函還在自己的瀏覽器裡，首頁會提示「幫它建立帳號」，角色等級也會一起帶上去
- 登入後，角色外觀、職業、等級、裝備、家具和邀請函都存在伺服器的 `data/accounts.json`（每 20 秒和離開總部時自動存檔），換手機、換電腦、Cloudflare 網址變了都拿得回來。密碼只存加鹽雜湊，不存明碼
- 同一個帳號只能在一個地方玩，在別的地方登入會把舊的那個擠掉
- 管理員介面 `/admin.html`：改派對日期和時間（報名頁、邀請函、IG 限時動態、總部的 VIP Pass 都會跟著換），查看帳號、幫忘記密碼的人重設密碼、刪除帳號。設定存在 `data/settings.json`
- Email：報到時一定要填 email，點了驗證信才能進總部。忘記帳號或密碼的人在登入頁點「忘記帳號或密碼？」，輸入帳號或 email，就會收到一封有帳號名稱和重設連結（30 分鐘、只能用一次）的信。登入後在識別證上方的「帳號設定」可以改密碼、換 email。以前的舊帳號沒有 email 也照常能玩，只會提醒去綁
- 寄信用 Resend，收信用 Cloudflare Email Routing，設定步驟見 [docs/mail-setup.md](docs/mail-setup.md)。還沒設 `RESEND_API_KEY` 的話信不會真的寄出，只印在終端機上，這時可以在管理員介面按「設為已驗證」幫人通過
- 換電腦架站的話，把整個 `data/` 資料夾一起帶走就好
- 更新提醒（上版流程見上面「架站與上版」）：伺服器每次重啟後，大家的畫面會跳出「總部更新了」，10 秒後自動重新整理（打怪中可以按「稍後」，2 分鐘後再提醒）。管理員介面的「預告更新」可以先倒數，時間到會先幫大家存好角色

## 小樹屋語音

設計細節（連線流程、視訊、中繼用量上限的取捨）見 [docs/design/treehouse.md](docs/design/treehouse.md)。

同一間小樹屋的人是兩兩直接連線通話（WebRTC），伺服器只幫忙交換連線資訊。手機 4G/5G、公司、學校網路常常不讓外面直接連進來，兩個人都在這種網路時就會互相聽不到（小樹屋卡片上那個人旁邊會顯示「連不上」）。這時要加一台 TURN 中繼伺服器幫忙轉送聲音。只有接不通的那幾對會走中繼，語音一小時大約 36MB，免費額度很夠用。

進了小樹屋，工具列上麥克風旁邊可以開視訊（320×240、每秒 15 張）跟分享螢幕（只有電腦版瀏覽器有）。畫面跟聲音走同一條連線，走中繼的那幾對開視訊一小時大約多 100MB、分享螢幕大約多 400MB，一樣算在 `TURN_LIMIT_GB` 上限裡，到上限就停發中繼通行證，不會超過免費額度。

### 用 Cloudflare（每月免費 1000GB，要綁信用卡）

1. 登入 [Cloudflare 後台](https://dash.cloudflare.com/)，左邊選單找 **Realtime**（舊名 Calls）→ **TURN Server** → **Create**，隨便取個名字。
2. 建好後會看到 **Turn Token ID** 和 **API Token**（API Token 只會顯示一次，先複製起來）。
3. 啟動時帶上這兩個值：

   ```bash
   CF_TURN_KEY_ID=你的TurnTokenID CF_TURN_KEY_TOKEN=你的APIToken npm start
   ```

   啟動訊息出現「小樹屋語音：使用 Cloudflare TURN 中繼」就成功了，大家重新整理、重新進小樹屋即可。

**不會超過免費額度**：大家的瀏覽器會回報走中繼的流量，伺服器記在 `data/turn-usage.json`，這個月用到 `TURN_LIMIT_GB`（預設 800GB）就停發中繼通行證，只剩直連。管理員頁面的「小樹屋語音中繼」可以看到這個月用了多少。Cloudflare 本身沒有自動停用的開關，建議另外到 **Manage Account → Billing → Billable Usage → Create budget alert** 設一個 1 美元的預算提醒，有任何收費就會寄信給你。

### 或用 Metered（免綁卡，每月免費 20GB）

到 [metered.ca](https://www.metered.ca/tools/openrelay/) 註冊、建一個 app，在 TURN Server 頁面拿 API Key，啟動時設 `TURN_API_URL="https://你的app.metered.live/api/v1/turn/credentials?apiKey=你的APIKey"`。兩種都設的話用 Cloudflare。

伺服器會自己去換臨時通行證給玩家，API Key / Token 不會傳到瀏覽器。這些值是密碼，不要 commit 進 repo。

```
server.js          伺服器：玩家同步、聊天、設定

shared/pets.js     寵物的外觀選項、存檔檢查和畫法（站、坐、睡三種姿勢）
pet-world.js       寵物在地圖上的行為：跟著主人、散步找路、一起打怪、可愛生物休息區的小窩

public/creatures.js 召喚師的奇異生物畫法
public/index.html  首頁：颱風假開趴報名頁（專屬 VIP 邀請函、IG 限時動態影片）
public/hq.html     遊戲頁：角色創建、聊天框
public/game.js     遊戲主程式（Phaser 場景、地圖與颱風的繪製）
public/crayon.js   蠟筆手繪風的繪圖小工具（抖動外框、顆粒、格紋）

public/icons-more.js 手繪 icon 第二批：每個技能、裝備、家具各一張（sk-／gear-／dec- 開頭）
public/style.css   介面樣式
```

想改地圖，就改 `shared/map.js` 裡的 `rect(...)` / `set(...)`；房間名稱在 `ROOMS`。
