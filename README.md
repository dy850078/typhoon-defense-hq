# 🌀 颱風天防衛總部

颱風假出不了門，就來線上總部集合吧！一個小小的多人線上世界：

- 🧑 創建自己的角色：蠟筆手繪風的人物，可以選髮型、髮色、膚色、雨衣顏色、要不要戴圓眼鏡
- 🚶 在總部地圖裡走來走去（方向鍵 / WASD，手機可以點地板走路）
- 💬 文字聊天，說的話會冒出對話泡泡
- 📦 到「物資倉庫」敲箱子（空白鍵或點箱子），敲三下會掉出泡麵、礦泉水或蔬菜；被拿走的箱子 60 秒後自動補貨
- 🍜 到休息區角落的「煮泡麵區」，站在爐台旁按空白鍵煮泡麵補血（有蔬菜會自動加進去，補更多），爐台會冒火冒蒸氣；點背包裡的礦泉水可以補魔力
- 🎒 右上角的「背包」、右下角的「技能」按鈕會打開視窗，看物品和技能說明，也可以直接使用。背包分成補品（15 格，一格疊 99 個）、雜物（20 格，家具一格疊 10 個）、裝備（30 格，同一件可以有好幾件，一件一格）三頁，按住一格拖到格子外面放開，就把它丟在地上給別人撿

- ✨ 打怪會噴東西：打倒怪物，補品、家具、裝備會噴在地上，誰都可以搶，走到旁邊按 Z 或點一下撿起來；地上的東西 60 秒沒人撿就消失。每隻怪的掉落表寫在 `shared/stats.js` 的 `drops`（沒寫的用 `DROPS` 預設），伺服器端在 `loot.js`
- ❤️ 每個人都有血量、魔力、攻擊力、防禦力，倒下後 5 秒回到總部
- 📂 到「指揮中心」找「轉職資料沈理員」就能換職業，每個職業都有自己的衣服、自己的普通攻擊（空白鍵），K 放職業技能：
  - 🦺 防颱職員（新手）：普攻 👊 一拳；⚡ 強力一擊
  - 🔮 預言家（輔助增益）：普攻丟水晶球（中距離）；任立瑜附體，削弱颱風、身邊隊友防禦變高
  - 🩺 南丁格爾（補師）：普攻用針筒打一針；生生好鮮乳，身邊所有人補血補魔
  - 🏹 精靈射手（遠距離）：普攻拉弓射箭（遠距離）；美麗聖潔弓箭
  - 🏋️ 超能力霸王（坦克）：普攻霸王拳；槓鈴老師，搥完自己防禦變高
  - ⛸️ 陵媒（控場）：普攻冰刀踢；冰嬉，繞颱風溜一圈把它冰凍 4 秒
  - 🛸 召喚師（召喚）：普攻外星光線（中距離）；召喚奇異生物
- 📈 等級越高越強：每升一等攻擊力 +2（普攻、技能傷害都會變高），補血量、加防禦、召喚物的攻擊和血量也跟著變強
- 🌀 走出圍欄到「颱風前線」，大家一起打颱風怪「薔琵」（名字在 `shared/stats.js` 改）。它會放強風、暴雨彈、落雷，出招前地上會先出現紅圈，快閃開！血量會隨在線人數變多，被打倒後 5 分鐘重新生成

- 🛡️ 圍欄裡面是安全區：怪物不會出來，也打不到圍欄內的人
- ⭐ 等級：打怪（造成的傷害、補的血都算經驗）會升等，每在線 10 分鐘也升一等；等級存在自己的瀏覽器
- 🎆 升到 Lv.5 後，按右下角的煙火按鈕，輸入文字，煙火就會在頭上炸開拼成那幾個字
- 📇 右鍵點別人（手機長按）→「個人資料」，可以看他在報名頁生成的 VIP Pass（要先在報名頁生成邀請函）
- 📹 走進「戰情室」按一下，就能和大家一起進 Jitsi 視訊
- 🎨 戰情室裡還有「你畫我猜」：主持人用滑鼠（手機用手指）畫畫、偷偷設好答案，其他人猜；猜對的人和主持人都會拿到一件裝備。沒有主持人時誰都可以拿起主持棒；想換人就按「搶主持棒」，超過一半的參與者同意就換人、遊戲重新開始（主持人一分鐘沒動作也可以直接接手）

- 🆕 從報名頁（邀請函）進來的人，一律從新手「防颱職員」開始
- 🛸 召喚師：在颱風前線召喚奇異生物（灰灰外星人、獨眼章魚、星星臉姊姊、鹿角毛毛蟲、聖誕樹外星人，越強越少見），牠們會自己去打怪，有血量，被打倒就不會回來；同時最多 3 隻
- 🪑 室內設計：打倒怪物有機會噴家具在地上，撿起來放在背包的雜物區；按右上角「家具」把家具擺在總部室內的地板上，大家都看得到。擺好的家具存在 `data/decor.json`，伺服器重開也還在
- 🧋 物資倉庫多了「台灣小吃」箱：台灣珍奶、台灣雞排，點一下就能吃，補血也補魔
- 🌧️ 窗外下著大雨，偶爾還會打雷
- 🎵 點歌：右上角「點歌」或走到休息區左上角的 🎧 DJ 台，打歌名搜尋 YouTube（或直接貼連結）就能排進隊伍。全場一台點唱機，所有人同步聽同一首；點歌的人可以直接切歌，其他人超過一半同意也能切。左上角的黑膠唱盤可以調音量、靜音（手機如果沒聲音，按「點一下開始聽」）

技術：Phaser 3（前端 2D 遊戲引擎）+ Node.js + Express + Socket.IO（即時多人同步）。不需要資料庫，也不需要物理引擎。

## 報名頁（首頁）

朋友打開網址會先看到「颱風假開趴」報名頁：上傳大頭照、填暱稱、拿手歌、今晚要喝的酒，選一張 VIP 卡顏色，就會生成：

- 專屬的「防颱總部」VIP 通行證
- 9:16 會動的 IG 限時動態影片（mp4），手機可直接分享到 IG 或存到相簿
- 報名完才會出現「進入颱風天防衛總部」的入口，暱稱會自動帶進遊戲

報名時會一起建立帳號，邀請函和角色存在伺服器的 `data/accounts.json`（不用資料庫），下次登入就能拿回來。

## 在自己的電腦啟動

需要先安裝 [Node.js](https://nodejs.org/)（18 版以上）。

```bash
npm install
npm start
```

打開瀏覽器到 <http://localhost:3000> 就能進去了。終端機也會印出這次的 Jitsi 視訊房間網址。

## 讓朋友連進來（不需要 public IP 或網域）

伺服器跑起來之後，再開一個終端機，用下面任一種「通道（tunnel）」把你電腦上的 3000 port 分享出去。它會給你一個公開的 https 網址，把網址傳給朋友就好。

### 方法 A：Cloudflare Tunnel（免費、免註冊）

1. 安裝 cloudflared
   - macOS：`brew install cloudflared`
   - Windows：`winget install --id Cloudflare.cloudflared`
2. 執行：
   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```
3. 畫面上會出現 `https://xxxx-xxxx.trycloudflare.com`，傳給朋友。

### 方法 B：ngrok

1. 到 <https://ngrok.com/> 註冊並安裝，照網站指示設定 authtoken。
2. 執行：
   ```bash
   ngrok http 3000
   ```
3. 把畫面上 `Forwarding` 那行的 https 網址傳給朋友。

> 注意：關掉終端機或電腦睡眠，大家就會斷線。快速通道的網址每次重開都會變，要重新傳一次。

## 帳號和管理員介面

- 首頁是登入頁：已經有帳號的人輸入帳號密碼就能拿回邀請函；第一次來的人按「報名領邀請函」，報名時順便設定帳號密碼
- 以前沒有帳號時報名過的人，邀請函還在自己的瀏覽器裡，首頁會提示「幫它建立帳號」，角色等級也會一起帶上去
- 登入後，角色外觀、職業、等級、裝備、家具和邀請函都存在伺服器的 `data/accounts.json`（每 20 秒和離開總部時自動存檔），換手機、換電腦、Cloudflare 網址變了都拿得回來。密碼只存加鹽雜湊，不存明碼
- 同一個帳號只能在一個地方玩，在別的地方登入會把舊的那個擠掉
- 管理員介面 `/admin.html`：改派對日期和時間（報名頁、邀請函、IG 限時動態、總部的 VIP Pass 都會跟著換），查看帳號、幫忘記密碼的人重設密碼、刪除帳號。設定存在 `data/settings.json`
- 換電腦架站的話，把整個 `data/` 資料夾一起帶走就好
- 更新提醒：伺服器每次重啟後，大家的畫面會跳出「總部更新了」，10 秒後自動重新整理（打怪中可以按「稍後」，2 分鐘後再提醒）。要更新前可以先在管理員介面「預告更新」，選 1／3／5 分鐘，大家畫面上方會倒數，時間到會先幫大家存好角色，再重啟伺服器

## 設定（環境變數，可不設）

| 變數 | 預設 | 說明 |
| --- | --- | --- |
| `PORT` | `3000` | 伺服器 port |
| `MAX_PLAYERS` | `40` | 最多同時上線人數 |
| `JITSI_ROOM` | 每次啟動隨機產生 | 視訊房間名稱，想固定的話自己設一個不好猜的名字 |
| `JITSI_DOMAIN` | `meet.jit.si` | 如果有自架 Jitsi 可以換掉 |
| `CF_TURN_KEY_ID` / `CF_TURN_KEY_TOKEN` | 不設 | 小樹屋語音用 Cloudflare 的 TURN 中繼，設定方法見下面「小樹屋語音」 |
| `TURN_LIMIT_GB` | `800` | 中繼每個月最多用多少 GB，到了就停用中繼（Cloudflare 免費額度 1000GB） |
| `TURN_API_URL` | 不設 | 或改用 Metered 的 TURN 中繼（免綁卡） |
| `TURN_URL` / `TURN_USER` / `TURN_PASS` | 不設 | 小樹屋語音的中繼伺服器（例如 `turn:example.com:3478`）；有人在公司、學校網路連不上語音時再加 |
| `MONSTER_HP` | `8000` | 颱風怪物的基本血量 |
| `MONSTER_HP_PER_PLAYER` | `2000` | 每多一位在線玩家，颱風多幾點血 |
| `RESPAWN_MINUTES` | `5` | 颱風被打倒後幾分鐘重新生成 |
| `CRATE_RESTOCK_SECONDS` | `60` | 物資箱被拿走後幾秒補貨 |
| `CAKE_CODE` | `CAKE` | 隱藏彩蛋的暗號（不分大小寫） |
| `ADMIN_PASSWORD` | 第一次啟動隨機產生 | 管理員介面（`/admin.html`）的密碼，沒設的話啟動時會印在終端機上 |

例如：`JITSI_ROOM=OurTyphoonParty2026 npm start`（Windows PowerShell：`$env:JITSI_ROOM="OurTyphoonParty2026"; npm start`）

## 關於視訊

- meet.jit.si 嵌在別人網頁裡的話，通話 5 分鐘後會被自動切斷，所以這裡是**開新分頁**進 Jitsi，大家會進同一個房間。

## 小樹屋語音

設計細節（連線流程、視訊、中繼用量上限的取捨）見 [docs/design/treehouse.md](docs/design/treehouse.md)。

同一間小樹屋的人是兩兩直接連線通話（WebRTC），伺服器只幫忙交換連線資訊。手機 4G/5G、公司、學校網路常常不讓外面直接連進來，兩個人都在這種網路時就會互相聽不到（小樹屋卡片上那個人旁邊會顯示「連不上」）。這時要加一台 TURN 中繼伺服器幫忙轉送聲音。只有接不通的那幾對會走中繼，語音一小時大約 36MB，免費額度很夠用。

進了小樹屋，工具列上麥克風旁邊可以開視訊（320×240、每秒 15 張）跟分享螢幕（只有電腦版瀏覽器有）。畫面跟聲音走同一條連線，走中繼的那幾對開視訊一小時大約多 100MB、分享螢幕大約多 400MB，一樣算在 `TURN_LIMIT_GB` 上限裡，到上限就停發中繼通行證，不會超過免費額度。

### 用 Cloudflare（每月免費 1000GB，要綁信用卡）

1. 登入 [Cloudflare 後台](https://dash.cloudflare.com/)，左邊選單找 **Realtime**（舊名 Calls）→ **TURN Server** → **Create**，隨便取個名字。
2. 建好後會看到 **Turn Token ID** 和 **API Token**（API Token 只會顯示一次，先複製起來）。
3. 啟動時帶上這兩個值：

   ```bash
   CF_TURN_KEY_ID=你的TurnTokenID CF_TURN_KEY_TOKEN=你的APIToken npm start
   ```

   啟動訊息出現「小樹屋語音：使用 Cloudflare TURN 中繼」就成功了，大家重新整理、重新進小樹屋即可。

**不會超過免費額度**：大家的瀏覽器會回報走中繼的流量，伺服器記在 `data/turn-usage.json`，這個月用到 `TURN_LIMIT_GB`（預設 800GB）就停發中繼通行證，只剩直連。管理員頁面的「小樹屋語音中繼」可以看到這個月用了多少。Cloudflare 本身沒有自動停用的開關，建議另外到 **Manage Account → Billing → Billable Usage → Create budget alert** 設一個 1 美元的預算提醒，有任何收費就會寄信給你。

### 或用 Metered（免綁卡，每月免費 20GB）

到 [metered.ca](https://www.metered.ca/tools/openrelay/) 註冊、建一個 app，在 TURN Server 頁面拿 API Key，啟動時設 `TURN_API_URL="https://你的app.metered.live/api/v1/turn/credentials?apiKey=你的APIKey"`。兩種都設的話用 Cloudflare。

伺服器會自己去換臨時通行證給玩家，API Key / Token 不會傳到瀏覽器。這些值是密碼，不要 commit 進 repo。

## 專案結構

```
server.js          伺服器：玩家同步、聊天、設定
shared/map.js      地圖資料（前後端共用）
shared/avatar.js   角色外觀選項與繪圖
shared/stats.js    角色數值、職業、技能、食物效果（調整職業和技能就改這裡）
shared/gear.js     裝備清單、稀有度和每件裝備的畫法
shared/decor.js    家具清單和畫法（室內設計）
shared/bag.js      背包三區（補品、雜物、裝備）的格數和上限
loot.js            地上的掉落物：打怪噴出來、從背包丟出來、撿起來
public/creatures.js 召喚師的奇異生物畫法
public/index.html  首頁：颱風假開趴報名頁（專屬 VIP 邀請函、IG 限時動態影片）
public/hq.html     遊戲頁：角色創建、聊天框
public/game.js     遊戲主程式（Phaser 場景、地圖與颱風的繪製）
public/crayon.js   蠟筆手繪風的繪圖小工具（抖動外框、顆粒、格紋）
public/icons.js    手繪 icon（職業、按鈕、提示泡泡…），沒有 emoji
public/icons-more.js 手繪 icon 第二批：每個技能、裝備、家具各一張（sk-／gear-／dec- 開頭）
public/style.css   介面樣式
```

想改地圖，就改 `shared/map.js` 裡的 `rect(...)` / `set(...)`；房間名稱在 `ROOMS`。
